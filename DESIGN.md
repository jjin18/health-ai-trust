# Direction

Three moments: Audiology within reach → Different rooms, still together → Bring care closer.

Warm blush-to-ivory light, large serif typography, a restrained hearing signal, and a continuous connection between a headphone icon (patient) and remote clinician icon. No staged photography, rendered hardware, feature grids, small promotional captions, or fabricated results.

The only category description is Remote audiology for ENT. The concept dialog explains that this is a proposed service and is not yet available. The contact dialog is a truthful placeholder until a contact destination is supplied.

Animation uses native scrolling and a time-based RAF smoothing loop, small compositor transforms, and a persistent line between the patient and audiologist. It respects reduced motion and page visibility.
